Research & thesis.

Academic research exploring explainable machine learning and sustainable irrigation.

Explainable machine learning · Unpublished, 2026

BioTheraX — Explainable ML for Breast Cancer Treatment Selection

  • Python
  • CatBoost
  • XGBoost
  • LightGBM
  • SHAP

Studied treatment selection using the METABRIC cohort: 1,904 patients, 704 features and 8 treatment categories.

Method: KNN imputation → consensus feature selection → SMOTE → model benchmarking.

Best-performing model: CatBoost using the Top-50 features.

Reported accuracy
89.16%
Reported AUC-ROC
98.6%
Smart agriculture · Unpublished, 2026

Automated AWD Rice Irrigation — Multi-Hop LoRa Network

  • Arduino
  • LoRa (SX1278)
  • Python (Flask)
  • Open-Meteo API

Investigated automated alternate wetting and drying (AWD) rice irrigation through a multi-hop LoRa network.

Sensing & scheduling: Ultrasonic sensing with 8-state RTC sleep scheduling.

Pump control: Weather-aware operation with a rain lock.

Reported water savings
39.4%
Reported energy savings
38.8%

Savings compared with continuous flooding.

Results reported from unpublished academic work (2026).
